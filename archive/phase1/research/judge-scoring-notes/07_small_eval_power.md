## 0. 结论

“200 题做出 1000 题的效果”在统计上只有三条真实可用的路，且都有上限：

1. **配对 + 每题多次试跑**：同一批题上逐题比新旧版本，再把每题跑 K 次取均值。按 Miller 公式，200 题 × K 次相当于 339–1000 道“单次试跑题”，具体取决于“版本间真实差异在题目间的方差 ω²”和“单题随机性 σ²”之比。只有 ω² ≤ σ²·(0.5 − 2.5/K) 时才到得了 1000（K=10 时要求 ω² ≤ 0.25σ²）。题间差异是压不掉的那一项。
2. **质量分用连续值做配对检验**：比 0/1 通过率信息量大，200 题在配对差标准差 0.15（0–1 量纲）时可检出 0.03 的差。
3. **便宜的代理分 + 少量可信分（prediction-powered inference）**：只有代理分与可信分相关 ≥0.9 且代理样本上千时才接近 5 倍；它省的是“可信打分”的钱，不省 agent 试跑的钱。

三条做不到的：
- 题目子集选择 / IRT / 锚点题（tinyBenchmarks、ATLAS 等）都要几十到几千个模型的逐题结果来标定，单个 agent、自造题用不上。
- 同一种子任务换城市、日期、人数的变体不是独立样本：有效样本量 = n·m / (1 + (m−1)ρ)。200 条如果是 40 个种子 × 5 个变体，ρ=0.5 时只相当于 67 条。
- 反复用同一批题做接受/拒绝，理论保证（Thresholdout、Ladder）在 n=200 时数值上是空的；能借的是机制（改进不超过一个配对标准误就不接受、留出集只回答“过/不过”、定期换新题），不是保证。

## 1. Miller 2024《Adding Error Bars to Evals》的具体建议

来源：[arXiv 2411.00640](https://arxiv.org/html/2411.00640) **[read primary]**

**五条建议（§1）**：用中心极限定理算均值的标准误；题目成组相关时用聚类标准误；用重复采样和 next-token 概率降方差；两个模型比较时对逐题差做配对推断；用功效分析判断一个评测能不能检验某个假设。另有三条容易漏掉的：
- §2.1：一般不需要 bootstrap，除非抽样方案或估计量复杂。
- §3.3：不要为了降方差去调采样温度。
- §5：新评测建议至少 1,000 题——这个数字出自它自己的算例（δ=3 个点、ω²=1/9），不是通用下限。

**公式**
- 配对标准误：`SE_paired = sqrt(Var(s_A − s_B)/n) = sqrt(SE_A² + SE_B² − 2·SE_A·SE_B·Corr(s_A,s_B))`；`Var_paired = Var_unpaired − 2·Cov(x_A,x_B)/n`。论文称之为“免费”的方差缩减。
- 聚类标准误：`SE_clustered = ( SE_CLT² + (1/n²)·Σ_c Σ_i Σ_{j≠i} (s_ic − s̄)(s_jc − s̄) )^½`；配对 + 聚类（式 8）是把 s 换成逐题差 s_{A−B}。
- 多次试跑的方差分解：`Var(μ̂) = (Var(x) + E[σ_i²]/K)/n`。算标准误时先对每题取 K 次均值，再跨题算；不能把 n×K 个结果当独立样本。
- K 的选法：让 `E[σ_i²]/K ≪ Var(x)`。论文的均匀难度算例里 K=2 减 1/3 方差、K=4 减 1/2、K=6 减 5/9，上限是 2/3。
- 功效：`n = (z_{α/2}+z_β)²·(ω² + σ_A²/K_A + σ_B²/K_B)/δ²`，`ω² = Var(x_A)+Var(x_B)−2Cov(x_A,x_B)`；聚类时把三个方差换成聚类版，公式不变（附录 C）。

**论文给的数字**
- 聚类比朴素标准误大多少（表 4）：DROP 3.05 倍、MGSM 1.88 倍、RACE-H 1.10 倍。
- 配对省多少：§4.2 的算例说相关系数 0.5 时方差“相对减少 1/3（1/6 → 1/9）”。**注意**：按该算例 Var(x)=1/12 复算，相关 0.5 应得 1/12（减半），1/9 对应的是相关 1/3；抓取结果也标了这处不一致，没有进一步查清是论文笔误还是相关系数定义不同。引用时只说“相关越高省得越多”，不引这个具体比例。
- 功效算例：ω²=1/9、σ²=0、δ=3 点 → n≈969；n=198、σ²=1/6、ω²=1/9 时 K 从 1 到 10，最小可检测差从 13.2% 降到 7.5%。
- 论文没有小样本指导；HumanEval（n=164）直接用了中心极限定理区间。真实前沿模型间逐题相关 0.3–0.7 的说法不在论文里（论文表 5 只有虚构模型的 0.50 / 0.64 / 0.37），05 号笔记把它归到 Anthropic 博客，本次未重新核对博客。

**两篇补充**
- Wang《Measuring all the noises of LLM Evals》（Meta FAIR，arXiv 预印本，2025-12，2026-03 修订）[arXiv 2512.21326](https://arxiv.org/html/2512.21326v2) **[read primary]**：把噪声分成预测噪声（同题重跑答案不同）和数据噪声（换一批题）。经验规律：单次试跑的配对差 `SE[A−B] ≈ sqrt(p(1−p)/N)`。配对之后预测噪声通常是大头（MATH500 上预测标准误约为数据标准误的 2 倍；SWE-bench 训练曲线上数据标准误约为预测的 1/6），所以多次试跑取均值很划算：HumanEval（N=164，准确率 0.5）配对 + 取均值把最小可检测差从约 8% 降到 2–4%。它也指出比例依赖温度（CRUXEval、T=0.2 时数据噪声反而占主导）。一对系统就能用，不需要很多模型。
- Bowyer 等《Position: Don't Use the CLT in LLM Evals With Fewer Than a Few Hundred Datapoints》（ICML 2025，PMLR 267）[arXiv 2503.01747](https://arxiv.org/html/2503.01747)、[PMLR](https://proceedings.mlr.press/v267/bowyer25a.html) **[read primary]**：N=100 时名义 95% 的中心极限定理区间实际覆盖约 92.5%；bootstrap 也不好。建议：单模型用 Wilson 或 Beta(1+成功数, 1+失败数) 后验；题目成组时用分层贝叶斯模型（它明确说 Miller 的聚类标准误在小 N 下达不到名义覆盖，且没有现成的频率学派替代）；配对比较用带相关系数的潜变量贝叶斯模型。论文刻意不给“N 大于多少就可以用中心极限定理”的阈值。代码库 `bayes_evals`。

## 3. 同一种子任务的模板 / 扰动变体

**公式** **[read primary]**：Kish（1965，《Survey Sampling》）的设计效应 `Deff = 1 + (m−1)ρ`，有效样本量 `n_eff = 总条数 / Deff = n·m / (1 + (m−1)ρ)`（n 个种子，每个 m 个变体，ρ 是组内相关）；各组大小不等时用平均组大小是保守上界。— [Design effect (Wikipedia)](https://en.wikipedia.org/wiki/Design_effect)。Kish 原书未读 **[could not verify]**。

**评测文献里的证据**
- Miller 2024 表 4：同一段落的多道题不做聚类调整，标准误被低估 1.10–3.05 倍（见第 1 节）。**[read primary]**
- 对 GSM-Symbolic（100 个模板 × 50 个变体）的重新分析：Długosz 等《The Importance of Being Statistically Earnest》[arXiv 2605.28700](https://arxiv.org/html/2605.28700) **[read primary]**；“EMNLP 2026 主会”是 arXiv comments 自述，未在 ACL Anthology 核对 **[could not verify]**。作者明确写同一模板的结果不应视为统计独立；改用带模板随机截距的广义线性混合模型（`Correct ~ Variant + (1|Id)`）并**按模板重采样** 2,000 次 bootstrap 后，20 个开源模型里只有 8 个的“变体掉分”显著，其中 5 个换 prompt 格式后不再显著；再控制“变体里数字更大”这一分布偏移后只剩 3 个“模型 × prompt”组合显著。论文没有报组内相关系数的数值。
- GSM-Symbolic 原文（ICLR 2025）[arXiv 2410.05229](https://arxiv.org/html/2410.05229)：同一模板不同实例的准确率是一个有明显方差的分布，只改数字所有模型都掉分。**[secondary，搜索摘要]**
- Messing《Hidden Measurement Error in LLM Pipelines…》（2026 预印本）[arXiv 2604.11581](https://arxiv.org/html/2604.11581v3) **[read primary]**：用方差分量模型，`Var(θ̂) = σ²_题/N + σ²_措辞/V + σ²_题×措辞/(N·V) + … + σ²_残差/(N·V·M·R)`。忽略这些分量时朴素标准误在 MMLU 上低估 57%；安全评测上覆盖率从 93% 掉到 80%。预算分配上先加题：题目数翻倍方差降 38.7%，措辞和温度各自贡献不到 5%，题 × 评委交互占 43.9%，只用一个评委方差增加 106%。
- 没有找到一篇论文直接测量“同一旅行/对话任务换城市、日期、人数后的组内相关” **[could not verify]**。

启示（推断）：
- 同样多跑一次，信息量排序是“新种子（ρ=0）> 变体（ρ_变体）> 原题重跑（ρ = 单题 ICC，文献 0.30–0.77）”。变体只有在 ρ_变体 明显低于重跑的 ICC 时才比多跑 K 次更值。
- 做版本比较时相关的是“逐题差”的组内相关，种子的固有难度在作差时被抵消，通常低于原始分的组内相关——所以变体对配对比较比对绝对水平更有用。这是推理，没有引文。
- ρ 可以实测：对每个种子算变体间方差与总方差之比。分析时按种子聚类（重采样种子，变体整组进出），划分开发/留出时按种子整组划分。

## 4. 反复复用小留出集做接受/拒绝的过拟合

**理论**
- Dwork 等《Generalization in Adaptive Data Analysis and Holdout Reuse》（NeurIPS 2015；Science 2015 版《The reusable holdout》未打开 **[could not verify]**）[arXiv 1506.02629](https://ar5iv.labs.arxiv.org/html/1506.02629) **[read primary]**。Thresholdout：分析者可随意看训练集；每次查询比较训练均值和留出均值，差在阈值 T（加 Laplace 噪声）内就返回训练均值——留出集只泄露“没过拟合”这一位信息；超过阈值才返回带噪声的留出均值并消耗一次预算 B。保证（定理 25）：留出集大小 `n ≥ O(ln(m/β)/τ²)·B`（m 为查询数、τ 为精度、β 为失败概率）——查询数可以随 n 指数增长，只要真正过拟合的次数不超过约 n² 量级。实验：n=10,000、d=10,000 个特征、标签纯随机，按“训练集和留出集上相关方向一致”选 500 个变量后，普通留出集报告准确率 63% 以上（真值 50%）；Thresholdout（T=0.04、τ=0.01、高斯噪声）没有出现这个假象。
- Blum & Hardt《The Ladder》（ICML 2015，PMLR 37）[ar5iv 1502.04585](https://ar5iv.labs.arxiv.org/html/1502.04585)、[PMLR](https://proceedings.mlr.press/v37/blum15.html) **[read primary]**。规则：新提交只有比历史最好成绩好出一个步长 η 才更新并公布，否则原样返回旧成绩。误差界 `O(log^{1/3}(kn) / n^{1/3})`，对提交次数 k 只有对数依赖；任何估计器的下界是 `Ω(sqrt(log k / n))`。不设防的排行榜可被攻到 `Ω(sqrt(k/n))`（提交 k 个随机标签向量，留下得分好的做多数表决）。**免调参版**：η 取“新旧两次逐题损失差的样本标准差 / √n”，即改进超过一个配对标准误才算数，作者说这相当于单侧显著性约 0.15 的配对 t 检验，是启发式，没有控制自适应和多重比较。
- 反面证据：Roelofs 等《A Meta-Analysis of Overfitting in Machine Learning》（NeurIPS 2019）[页面](https://papers.nips.cc/paper/9117-a-meta-analysis-of-overfitting-in-machine-learning) **[read primary，仅摘要]**：一百多个 Kaggle 比赛的公开榜（反复复用的留出集）与最终榜对比，没发现显著过拟合的证据。比赛数“120”只见于搜索摘要 **[secondary]**。

**对 n=200 的含义（推断）**
- 两个理论保证在 n=200 时数值上没用：Thresholdout 取 τ=0.05 时 `1/τ²=400` 已超过 200；Ladder 的 `(ln(kn)/n)^{1/3}` 在 n=200、k=50 时约 0.36（常数未计）。能迁移的是机制。
- 噪声选择的量级：k 个真实效果为 0 的候选里挑最好的，期望虚高约为配对标准误的 1.16 / 1.54 / 1.87 / 2.25 倍（k=5 / 10 / 20 / 50，标准正态最大值的期望）。200 题、版本间不一致率 15% 时配对标准误约 2.7 点，20 个候选里最好的那个平均“白涨”约 5 点。
- 免调参 Ladder 的门槛在 0/1 指标下约为 `sqrt(不一致率/n)`：n=200 时 2.2 / 2.7 / 3.2 / 3.9 点（不一致率 0.10 / 0.15 / 0.20 / 0.30）；n=100 时 3.2 / 3.9 / 4.5 / 5.5 点。
- Roelofs 的“没怎么过拟合”来自留出集通常成千上万条的比赛，不能直接搬到 200 条。

## 5. 从业者指南

- Anthropic《Demystifying evals for AI agents》[页面](https://www.anthropic.com/engineering/demystifying-evals-for-ai-agents) **[read primary]**：20–50 条来自真实失败的简单任务就可以起步，早期改动效果大所以小样本够，成熟后需要更大更难的集合才能检出小差异；每题多次试跑；通过率到顶的题“毕业”进回归集，集合要持续加新题。**本次确认该文没有讨论过拟合、留出集，也没有讨论用模型生成评测任务及其风险。**
- Hamel Husain FAQ（同上）**[read primary]**：先读约 100 条轨迹，读到不再出现新失败类型为止；模型评委每种失败类型要 100–200 条标注；合成数据用“先定维度 → 手写约 20 个维度组合 → 让模型扩组合 → 另一个 prompt 把组合写成自然语言”，直接让模型“给我测试问题”会得到泛泛而重复的东西；合成数据不能反映某种失败在生产里有多常见；评测集会过时，要靠定期错误分析刷新，刷新后分数不再可比是可以接受的；一直全过的评测应少跑或退役。
- OpenAI 评测最佳实践 [页面](https://developers.openai.com/api/docs/guides/evaluation-best-practices) **[secondary，搜索摘要]**：数据来源混合（合成、人工、生产、历史），覆盖典型 / 边界 / 对抗样例，警告评测集与生产流量分布不一致，建议持续评测并不断加题；搜索结果里没有集合大小或留出比例的建议。
- 用模型生成评测题的风险：
  - Xu 等《When LLMs Benchmark Themselves》（EMNLP 2026 主会，pp. 14447–14462）[ACL Anthology](https://aclanthology.org/2026.emnlp-main.629/) **[read primary，摘要]**：模型生成的评测集系统性偏向生成它的模型；偏差有“出题”和“判分”两个来源，叠加后更强，强到每个模型都把自己排第一；即使加了多样性控制，模型自己的文风仍使题目同质化；提高源文本多样性只能部分缓解。主要实验是机器翻译，另在开放生成上复现。
  - Gill 等《What Has Been Lost with Synthetic Evaluation?》[arXiv 2505.22830](https://arxiv.org/abs/2505.22830) **[read primary，摘要]**；venue 未写 **[could not verify]**：模型生成的题大多符合标注规范，但对模型来说比人写的题更容易。
  - Maheshwari 等 [arXiv 2409.11968](https://arxiv.org/abs/2409.11968v1)、Li 等“preference leakage” [arXiv 2502.01534](https://arxiv.org/pdf/2502.01534)、Silencer [arXiv 2505.20738](https://arxiv.org/html/2505.20738v1) **[secondary]**：合成基准在简单任务上能保持方法排序、难任务上不行；出题模型与评委同源会抬分；多个出题模型加权可把与人工基准的一致性从 0.655 提到 0.833。
  - 05 号笔记已收：commerce agents 一文认为“模型扮演用户 + 评委打分”的模拟对话方差大、难归因，宜用来发现问题再固化成快照。
- 没有找到任何官方指南给出“留出集多久轮换 / 重新生成一次”的具体频率 **[could not verify]**；最接近的是 Hamel 的“测试集被看过后换一份新的”和 05 号笔记里 agentskills.io 的“优化结束后再写 5–10 条全新的”。

## 6. 落到 200 题上（推断，供方案取舍，不是项目事实）

1. **先分清 200 条里有多少个独立种子**。按种子聚类算一次组内相关，用第 3 节的表换算有效样本量；之后所有区间、检验、划分都以种子为单位。
2. **划三份并按种子整组划**：反馈集（反思循环读轨迹）/ 选择集（接受或拒绝）/ 封存集（只在阶段性节点跑）。GEPA 与 gskill 都是三段式；DSPy 与 GEPA 的经验是选择集要比反馈集大。
3. **接受规则用“配对差超过门槛”而不是“分数更高”**：对 0/1 规则通过率和连续质量分各算逐题配对差，按种子聚类算标准误；门槛至少一个配对标准误（免调参 Ladder），想更稳取 1.64 倍。n 小于两三百时区间用 Wilson / 贝叶斯而不是中心极限定理（Bowyer）。同时看逐题翻转数，净涨 1 题而翻转十几题的修改不算改进（Mitra & Mahmud）。
4. **两级评估省钱**：候选先在反馈集的小批上比父版本好，才跑整个选择集（GEPA）；小批里放更多不同的题而不是同题重复（NeurIPS 2026 workshop 的 10 → 50 结果）。旧版本的结果缓存复用，每题 K 次。
5. **K 取 3–5**：表里 K 从 1 到 3 收益最大，5 之后变小；ICC 高（题目要么总过要么总挂）时加 K 无用，应把预算换成新种子。
6. **限制泄露**：循环只从选择集拿到“过 / 不过”，不把选择集的轨迹喂给反思模型（Thresholdout 的思路）；记录已评过的候选数 k，按第 4 节的 1.16–2.25 倍标准误估计“白涨”量；每过一批候选后新生成一批种子替换封存集，报告选择集与封存集的差距。
7. **给 prompt / Skill 文件设长度上限**（Decagon 的 1,500 字符做法），因为过拟合的主要形态是越改越长、堆窄规则。
8. **出题与判分**：出题模型不要和被测模型、评委模型同源；用“维度组合 → 自然语言”两步生成并人工过一遍；合成题偏易，要有意造中等难度题。

## 附：复算脚本（Python 标准库）

```python
import math
from statistics import NormalDist
nd = NormalDist(); c = nd.inv_cdf(0.975) + nd.inv_cdf(0.80)          # 2.8016
mde    = lambda w2, s2, K, n: c * math.sqrt((w2 + 2*s2/K) / n)        # 第 1 节表
equiv  = lambda w2, s2, K, n: n * (w2 + 2*s2) / (w2 + 2*s2/K)         # 等效单次试跑题数
n_eff  = lambda seeds, m, rho: seeds * m / (1 + (m - 1) * rho)        # 第 3 节表
ppi    = lambda rho, n, N: n / (1 - rho*rho / (1 + n/N))              # 第 2 节表
ladder = lambda PD, n: math.sqrt(PD / n)                              # 免调参 Ladder 门槛（0/1 指标近似）
def emax(k, dx=1e-3):                                                 # k 个标准正态最大值的期望
    return sum(x*k*nd.pdf(x)*nd.cdf(x)**(k-1)*dx for x in (i*dx - 8 for i in range(16000)))
print(mde(0.05, 0.08, 3, 200), equiv(0.02, 0.08, 10, 200), n_eff(40, 5, 0.5), ppi(0.9, 200, 1000), ladder(0.15, 200), emax(20))
# 0.0637  1000.0  66.7  615  0.0274  1.867
```
