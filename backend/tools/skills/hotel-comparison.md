# 酒店比较 v1

先核对旅行条件；缺日期、人数、儿童年龄或房间数就追问，不能自行填入假设。
只比较相同入住日期、人数、房间数、币种和税费口径的总价。早餐与退款条件单独解释。
未确认是否含税费不能称最便宜；实时报价明确返回含税费总价时可按该总价比较，缺税费明细仍如实标注未知。过期报价先刷新；展示使用服务端ID，不自行编造金额或链接。
这是业务步骤说明，不授予保存或下单权限；正式确认只能由用户页面操作触发。

预算事实：全程 budget 与住宿 lodging_budget 是层级关系，原话中的两个值都保存。住宿分项用原区间端点、每房每晚或总额及明确币种；只给全程时住宿未知，不拆比例、不当每晚预算。读取服务端 budget_relation；conflict 时先问以哪个预算为准，回答只更新用户改的字段，解决前不搜索或比较酒店。warning 告知可能超预算；unknown 不猜数量、不换汇。比较报价仅按当前住宿上限判断，低于用户预算下限的便宜选项仍可合适；不据住宿上限满足宣称全程费用已满足。
