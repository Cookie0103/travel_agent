# 能力质量与验收缺口

这不是任务进度副本或主观百分制。实时任务/提交/命令结果唯一来源：[执行计划](execution/travel-agent.md)。
等级：A=代码、相关失败测试和场景证据经过独立复核；B=已实现验证但部分验收缺失；待验=尚无足够证据。
等级只针对列明的能力范围，测试数与通过率不代表模型质量或生产可用。

新增能力在证据形成后更新本表，不预填分数。模型替身只证明工程链路，不能计为真实模型效果。
重大问题和技术债需注明影响范围、下一步验证和task/ADR链接；修复通过后保留原失败证据。
每个功能增量按实际变更运行专项；完整dev check/test在保存关卡执行一次，正常Git钩子按仓库要求再执行。

同SDK基线/单因素机制：ADR012、实际CLI与PG验证B0/B2/完整配置及Skill/偏好/修复/压缩开关；未知版本、意外压缩与非法组合失败路径通过独立复核。指标区分独立参数答案与unknown，首次进度排除ACK；这些工程证据不代替真实模型完整对照/语义质量评分。

私有事实/内容评审设施：实际PG捕获原回答/Evidence，按原case/context/hash独立标注与领域字段投影；缺完整必需事实或未知附件时比率null。内容/语气固定温度零工具SDK入口共享，三维真人校准可离线重算。设施经正常完整钩子和独立审查验证；当前实际内容评分、语义全量统计与真人配对仍未完成，不提升模型质量等级。三真实坏例矩阵见review/M3，邻近抹茶数据失败、规划partial及阈值预声明偏差保持开放。
