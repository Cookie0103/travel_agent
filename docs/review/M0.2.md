## 主调用链
uv --env-file 加载本地配置 → 显式 live pytest → load_settings → run_probe。
run_probe 拿锁并记录流程开始 → request 先记费用与次数，再调用 DeepSeek。
第一轮收到 tool_use → 本地返回合成结果 → 第二轮携带完整消息续接并要求结束。
账本与脱敏摘要在 .cache/m02-protocol；思考文本只在内存中续接，不写报告。

## 不变量与保护测试
- 默认不调用模型：test_default_pytest_deselects_live_probe。
- 换模型必须换计价、未知模型拒绝：test_selected_model_changes_pricing_without_exposing_secret 等。
- 人民币不能借美元额度：test_currency_budgets_cannot_borrow_from_each_other。
- 失败/超时仍计次且不重试：test_http_failure_consumes_one_attempt_without_retry_or_body_leak 等。
- 四次请求上限跨进程/跨天保持：test_restart_and_new_day_do_not_reset_batch_request_count。
- R02 的 ID 配对及思考块内存续接：test_roundtrip_preserves_thinking_and_pairs_reordered_results。

## 失败处理
缺模型/密钥/预算在请求前拒绝；HTTP、限速与超时只写分类，不输出异常原文。
不完整流、重复工具 ID、非法参数、第二轮仍想调用工具都失败，不无限循环。
账本损坏或锁遗留时停止，不能删记录后重新获得次数；这是本地探针的保护，不是业务恢复系统。
真实命令先被自动审批拦截；用户明确授权后同一命令通过。首轮 2 个工具调用，次轮结束。

## 取舍
使用已有 ADR-000 指定的 anthropic SDK 解析流，避免在实测中自写 HTTP/SSE 解析器。
预算先计保守上界且不退款；更精准的结算更复杂，本次少量实测不需要。
不逐项追加真实请求：未覆盖项标“无法判断”，一次 200 不能证明字段被忽略。
