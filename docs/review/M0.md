- 主调用链：live 测试 → sdk_probe.flow → 私有工作进程 → Claude Agent SDK / CLI → MCP 合成工具。模型 HTTP 经过 guard → budget → 有界 HTTPS 进程。

- 不变量：只有指定工具/模型；先预占后联网；完整单调 usage 才结算；次数不退款；终止进程时关闭后代。对应 tests/test_sdk_guard、budget、response、lifecycle、cli_offline。

- 简洁性复核：工具参数交给 SDK schema；删除重复 socket watchdog 与单行转发包装，保留受控进程总期限。实际 SDK/CLI 离线错误回填用例保护失败路径；独立复核通过。
- 取舍：标准库请求守卫 + 全上下文预占；仅用 SDK max_turns/max_budget_usd 无法保证 DeepSeek 请求数与人民币边界。守卫额外进程有启动成本，换来可终止的网络期限。
- 限制：只证明此版本的合成只读往返；用户文本、业务状态、恢复和压缩还需后续验收。版本/费用详情见 [接入记录](../protocol-agent-sdk.md)。
