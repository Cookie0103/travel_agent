# Travel Agent 项目表述草稿

面向AI应用/Agent研发岗位。仅是基于仓库证据的审计稿，未发布；个人贡献、项目时间与理解程度待用户集中学习后确认。开发由用户确定目标、SDK路线和费用边界，Codex实施并经独立审查，不包装成全部手写或自研runtime。

## 候选表述

- 【个人贡献待确认】基于Claude Agent SDK构建京都旅行助手，复用工具循环、会话续接和上下文压缩；实现旅行条件、事实证据、行程校验与稳定ID局部修改，版本检查和用户确认保护正式写入。
- 【个人贡献待确认】实现模拟酒店报价刷新、同口径比较及预订幂等；使用真实PostgreSQL与本机HTTP验证供应商丢响应、提交前后进程退出和按client_ref对账，保留unknown状态，避免盲目重新下单。
- 【个人贡献待确认】通过API、Next工作台和独立Compose提供离线业务演示；导入带许可/来源的146个OSM地点、20段Wikivoyage攻略，事件持久化与SSE支持断线读取，未知路线、税费和营业时间保持未知。
- 【个人贡献待确认】建立历史30例与冻结20dev/40test的隔离评测，记录工具、状态副作用、原币种费用、时延及可恢复运行证据；固定温度语气评审复用同一SDK，解析错误单列，真人校准未完成。
