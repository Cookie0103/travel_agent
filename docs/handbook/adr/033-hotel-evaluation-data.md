# ADR-033 酒店评测世界的数据来源

日期：2026-11-28
状态：合成夹具可用，乐天离线快照用途待确认

## 来源

- 车站取 Wikidata P625，保留每条记录的公开实体链接。精度用于评测位置分的近似距离。[Wikidata 结构化数据许可](https://www.wikidata.org/wiki/Wikidata:Copyright)
- 合成夹具固定种子 20261127，覆盖京都、大阪、奈良、东京、札幌、福冈，每城 16 家自造酒店。每家有三种日期需求、一人及两人的合成含税房价和完整属性。
- 普通酒店模拟佣金为 8%–12%。每城第 1、5、9、13 家设为模拟合作酒店，比例 25%，同样的基准加 3 个百分点。佣金表与可展示的酒店数据分开；合作语义属于评测。
- 乐天的空室接口是有条件使用的供应商数据。规约的禁止事项限制超出规定用途、共享存储和特定人员访问环境。本仓库目前没有该离线快照用途的供应商许可记录。C1 保留已批准的一次性录制安排，等待用途确认，当前真实查询 0 次。[乐天空室接口](https://webservice.rakuten.co.jp/documentation/vacant-hotel-search) · [乐天 Web 服务规约](https://webservice.rakuten.co.jp/guide/rule)

## 使用

现有合成文件用于开发和离线联调，显式标注合成来源。正式实验记录实际数据版本，乐天快照单独记录来源和查询数。评测加载时核对文件 SHA-256；生成器从仓库根目录通过 `uv run python -m data.eval_world.generate` 运行。
