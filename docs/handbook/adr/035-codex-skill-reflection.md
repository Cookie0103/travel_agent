# ADR-035 用受控 Codex 子进程生成 Skill 候选

日期：2026-11-28

状态：已采用

## 背景

第二阶段由 Codex 负责反思，旅行 Agent 仍走 Claude Agent SDK。反思仅提议 Skill 修改，成对回放、验收门槛和候选审核由独立代码执行。

## 决策

- 第一版接收本地结构化提案或显式请求 Codex 提案。Codex 通过标准输入接收 Skill 文本和反思组轨迹，并按 `Proposal` JSON Schema 返回。进程在空临时目录中以只读沙箱运行，禁用 shell、用户配置、钩子、插件和网页搜索。命令及投影见 `eval/evolve/codex.py`、`eval/evolve/round.py`。
- 报价佣金、按酒店的收益、验证组与留出组都不进入反思输入。第二版按失败类别一次只改一句，使用验证组和四道闸做回放。两版都只生成候选及审核页，合并由用户审核决定。
- 正式命令接收本地提案。回放沿用基线的本机运行方式，也能复用已有成对结果。候选目录和未审查的原始记录放在 `.cache`，可发布审核页的入口见[候选审核](../../phase2/evolution/README.md)。
