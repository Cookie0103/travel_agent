# ADR-025 有引用的衍生用户画像

日期：2026-10-14；状态：实施中。依据本批V2 T5b，预算有余时可实现；不新增依赖或runtime。

用户点击“更新我的画像”时调用ADR-011的相同SDK无工具、固定温度、DeepSeek预算路径；没有后台自动付费。输入仅active long_term事实，复用30条/2000字符快照上限，不带原始对话或其他会话trip。输出最多6句/600字符，每句引用输入中实际存在的本人active fact；外人、失效、无引用或残缺引用整句丢弃。引用存在仅证明来源可追溯，不能当成语义人工校准。

user_profile_summaries保存正文、引用、生成时间及偏好版本。任何事实变更同事务清正文/引用并标作废；删除同时推进偏好版本。生成前后核对revision及所有引用，遗忘/更新发生在生成途中时结果409不保存。有效摘要额外作为低优先级业务快照注入，当前明确条件优先；偏好消融同时移除memory和profile_summary。

默认非live API拒绝生成，GET不调用模型。前端不显示内部UUID，将来源说明为已确认长期偏好。服务端SDK结构化入口由provider提供，评测只重导出这一函数，避免复制模型调用/计费/身份校验代码。

加法迁移0021可回退删除派生摘要表，事实仍保留。实际PG/Chrome/模型证据从当前批次读取；未通过最终验收前不标完成。
