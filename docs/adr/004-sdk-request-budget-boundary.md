# ADR-004：SDK 请求与费用边界

状态：accepted（2026-10-03，落实已授权的 SDK 路线和 5 CNY / 100 次总额）。

SDK 的轮次限制无法覆盖隐藏的 HTTP 重试。采用仅监听回环地址的请求守卫：只接受 Messages 路径、明确模型、纯文本/工具 JSON 和有限输入/输出，转发到固定 DeepSeek HTTPS 地址；不做模型路由、不引入第二套运行时。

真实密钥只在费用守卫和受控 HTTPS 传输进程中，CLI 只得到随机的本地访问令牌。传输进程通过 stdin 获取密钥，整个 DNS/连接/读取设总期限；Windows Job 加启动握手保证回收后代。SDK 在环境变量白名单的 Python 子进程中运行；隔离个人 Claude 配置来源，禁用内置工具、插件、Skills、常规网络重试和非必要联网。工具循环完全由 SDK 负责。守卫与工作进程使用标准库，不新增网络服务器依赖。

请求发出前将次数与保守费用 fsync 落盘，整个实测持有文件锁、单个请求顺序处理。每个请求按其请求体 UTF-8 字节数（×1.25＋1024 token 固定开销，任何分词器每 token 至少 1 字节）和 max_tokens 输出，以最高输入价预占（2026-10-05 由整个 1M 上下文改为此，典型 25KB 请求约 0.08–0.13 元）。完整 SSE 的最终 usage 验证后追加结算，释放未用的预占；失败、未知 usage 或中断保持全部预占。只允许文本和有限嵌套的工具结构，拒绝图像、URL/服务端工具和容器功能。旧账本中约 2.11 元的历史预占保持不变；余额不足时保守停止。

账本同时检查本轮累计、UTC 当日额度及旧探针同日保守占用。锁/账本异常关闭收费部分，不自动清零。原来的人民币与美元边界不变。

备选：仅使用 SDK max_budget_usd 不适用 DeepSeek 人民币；改写 SDK 内部 HTTP 客户端容易随版本漂移；直接把真实 key 交给 CLI 则无法在父进程准确拦截每次付费请求。

限制：这不是防御恶意本机进程的 OS 沙箱；私有运行目录仍须由服务进程保护。价格与 token 上界须用实际 usage 验证，任何超界或未知协议特性终止该轮，不擅自扩大预算。M0.2 只验证合成只读工具。

来源：[SDK Python 选项](https://code.claude.com/docs/en/agent-sdk/python)、[CLI 环境变量](https://code.claude.com/docs/en/env-vars)、[DeepSeek 人民币价表](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)。

2026-10-03本机真实CLI核查：设置常规retry=0仍会在max_tokens后进行四次SDK内建输出续请求，不能宣称彻底关闭所有辅助请求。所有续请求仍经Guard实际HTTP计数和累计/每日预占；失败不由应用自动重跑。已知max_turns最终结果保留tool_use，失败分类按终止原因优先。DB完整8工具+回答在6轮必断，故该模式12SDK轮；普通搜索6、实际HTTP12/工具16/三修复及授权不变，证据见M3集中记录。
