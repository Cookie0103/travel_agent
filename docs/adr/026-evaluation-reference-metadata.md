# ADR 026：评测参考摘要与通过门槛分离

日期：2026-10-14；状态：采纳；依据：Claude修复计划F7/F8及用户确认。

内容模型分为未校准参考分，默认二值参考阈值3，可配置1–5并写manifest；不进入规则任务通过门槛。评审输入增加封闭JudgeEvents，只含注册工具名、结果码、choice_card、实际HTTP尝试、实际data_mode以及预算/记忆卡存在性。RuntimeEvent记录ToolResult实际来源类型，不从环境或评测身份推测。

多轮参考只使用当前回答对应run的事件，复用已有严格run分组/身份规则；数量、session、presentation或候选回答不吻合则未知，不借历史卡支持当前说法。缺旧来源也是未知。摘要不输出UUID、参数正文、报价、地名或第三方资料。

F8在同一事件契约中增加参数封闭事实，用于分诊线索；不新增运行时或依赖。原始记录只读；人工未完成时不给κ或根因准确率结论。公共Trace继续不含正文与记忆引用。历史评分和分诊本批不重新调用模型。
