# M4 交付规格

依据plan/04 M4、plan/05评测与ADR-000/005；进度唯一入口为[执行计划](../execution/travel-agent.md)。不改变已有业务范围、SDK或授权。

## M4.1 可运行交付

- 独立Compose演示项目运行API、Next前端、PG17与mock_supplier；不复用/删除现有开发数据库、容器或卷。默认离线，不向镜像/Compose传入模型密钥。启动先迁移并导入已校验快照，持久化PG与恢复证据；重启不自动调用模型/下单。
- 复用现有业务/迁移/导入入口，补容器所需监听与同源代理配置；宿主发布端口仅127.0.0.1。提供跨平台启动、状态、停止命令；停止不删卷。干净专用演示库实际启动→健康→认证→业务演示→重启持久性验证。
- Langfuse沿用ADR-000/005已接受Cloud替代，不越过禁止Redis/消息队列决策安装自托管栈。导出功能和本机OTLP回归保留；页面可见性仍需项目凭据，不伪造验收。M4.1“包括Langfuse”的UI验收在外部条件满足前保持partial。
- CI配置与本地对应check/test/web-check/build分别记录；未push，不声称远端CI通过。任何CLI未安装导致的SDK测试缺口必须显式暴露。

## M4.2 冻结评测

- 新冻结suite合计60条（20dev/40test，plan/05 §3）；历史30条保留独立入口与manifest，不改原失败期待。列明哪些旧例进入新dev、哪些仅保留历史回归，不重复计数；不把旧dev改成未见test。冻结记录版本/hash，test不用于调优；若看到test后改变规则/优化，另建版本并披露污染，不覆盖原记录。
- 通过现有服务构造既有正式行程、Evidence/过期报价、模拟预订/故障等初始状态，执行原禁止副作用断言；每例每轮独立身份/session且恢复同一初始状态。当前InitialState仅条件/拒绝故障的能力需补齐，不能仅增加自然语言输入凑60，也不能将协议单测计为业务成功率。
- 提供按同一冻结集运行3次及波动/分母/未执行/原币种/token/时延的报告能力；未知字段不填零，不混合币种或版本，规则评分和模型质量分开。
- 全量真实请求遵守[执行计划](../execution/travel-agent.md)中的最新授权：DeepSeek每日最多15 CNY且服从.env更低上限，无累计金额/次数上限，USD仍未授权。40例×3轮尚不含工具往返/评审；每日余额不足时保留结果并停止，不保证一日完成，不自动重新付费回放失败。多模型与人工分数不虚构，不降重复要求。
