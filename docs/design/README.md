## 怎么使用

- **第一次读**：01 了解范围 → 02 §0 的 6 个概念和 §1 主调用链 → 04 选当前任务。
- **开发时**：从 04 选一个任务 ID，只读 02 / 03 里相关的部分和 05 里对应的验收；需要查依据时再看 06。不需要每次把全部文档交给 AI。
- **个人准备**：HTML 第 04 节是日常开发流程，第 05 节是每个阶段要亲自做的验证。

实施顺序：M0 SDK 接入验证 + CLI 薄片 → M1 业务闭环 → M2 模拟预订与恢复 → M3 对照实验与生态 → M4 交付。

同一条规则只在它所属的文档里维护，其他文件引用。执行时持续更新长程执行计划的状态、决定和验证证据；04 不再重复维护状态。自动质量关卡通过后立即继续，用户最终集中审阅学习。

## 与其他作品项目的分工

本项目重点证明 Agent 能力。数据库事务、队列竞争、压测由**后端项目**负责；文档切分、向量检索由 **RAG 项目**负责。本项目不重复实现这两部分。
