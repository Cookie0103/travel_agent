# 离线测试数据

`kyoto.json`：自编景点/攻略测试集，旧CLI使用；不是实时事实。
`hotels.json`：6家完全虚构酒店、12个房型与退款/早餐组合，全部日元模拟价格。
金额以字符串存储，运行时转Decimal；按房晚计算，周末加价，税/费单列。
入住者含儿童全部占容量，不猜测婴儿免费。范围2026–2030，超出无报价。
缺税/缺费用组合用于失败测试；不得宣称最低总价或全程预算满足。
每次查询生成5分钟有效的新offer_id，完整快照存入本人会话的Evidence。
文件为本项目自编，无真实酒店库存、预订链接或外部数据许可依赖。
`routes.json`：4对地点的步行/公交自制双向估算，方向对称仅为演示假设。
分钟和每人费用不是实际路线/票价；全员金额包含每个儿童，无折扣，人数不全时费用未知。
未覆盖地点/交通方式返回unknown，不套直线距离或猜测出租车价；route证据有效15分钟。
