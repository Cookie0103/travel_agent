## 怎么使用

- **首次阅读**：01 了解范围 → 02 看主调用链 → 04 选当前任务。
- **实际开发**：从 04 选一个任务 ID，按需读 02/03 的相关契约和 05 的对应验收；查上游依据时再读 06，无需每次把全部文档交给 AI。
- **个人准备**：HTML 第 04 节是日常开发循环，第 05 节是各阶段亲自验证的任务。

实施顺序：M0 契约验证 → M1 业务闭环 → M2 可靠执行与归因 → M3 上下文与规划对照 → M4 性能实验与交付。

同一规则在所属文档维护，其他文件引用；完成任务后更新 04 的状态和验证证据，不另建一份重复进度表。
